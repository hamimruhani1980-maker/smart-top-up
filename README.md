💎 Smart Top Up

🎮 Smart Top Up-এ আপনাকে স্বাগতম!

Smart Top Up হলো গেমারদের জন্য একটি সহজ, সুন্দর ও ব্যবহারবান্ধব গেমিং টপ-আপ প্ল্যাটফর্ম। আমাদের উদ্দেশ্য হলো বিভিন্ন গেমের টপ-আপ সংক্রান্ত তথ্য এক জায়গায় সুন্দরভাবে সাজিয়ে দেওয়া এবং অর্ডার প্রক্রিয়াকে সহজ করা।

🎯 আমাদের লক্ষ্য

গেমারদের জন্য সহজে বোঝা যায় এমন তথ্য, পরিষ্কার মূল্য এবং সহজ অর্ডার প্রক্রিয়া তৈরি করা। আমরা চাই, একজন নতুন গেমারও যেন ওয়েবসাইট ব্যবহার করতে গিয়ে বিভ্রান্ত না হয়।

🛒 অর্ডার করার আগে

- সঠিক Game ID / Player ID / UID প্রদান করুন।
- অর্ডার দেওয়ার আগে গেমের নাম ও প্যাকেজ ভালোভাবে যাচাই করুন।
- পেমেন্ট করার আগে মোট মূল্য দেখে নিন।
- ভুল তথ্য দেওয়ার কারণে সমস্যা হলে অর্ডারের তথ্য যাচাই করে ব্যবস্থা নেওয়া হবে।

⚠️ গুরুত্বপূর্ণ নিরাপত্তা সতর্কতা

কখনোই আপনার Game Account-এর Password, OTP, PIN, Recovery Code বা অন্য কোনো গোপন তথ্য কারও সঙ্গে শেয়ার করবেন না।

টপ-আপের জন্য প্রয়োজনীয় Player ID/UID ছাড়া গোপন তথ্য চাওয়া হলে সতর্ক থাকুন।

💰 পেমেন্ট

পেমেন্ট করার আগে সব তথ্য ভালোভাবে যাচাই করুন। ভুল নম্বর, ভুল পেমেন্ট মাধ্যম বা ভুল তথ্যের কারণে তৈরি হওয়া সমস্যার ক্ষেত্রে প্রয়োজনীয় যাচাই করা হবে।

🔄 অর্ডার, বাতিল ও রিফান্ড

অর্ডার সফলভাবে সম্পন্ন হওয়ার পর সব ক্ষেত্রে অর্ডার বাতিল বা রিফান্ড করা সম্ভব নাও হতে পারে। রিফান্ড বা বাতিলের সিদ্ধান্ত অর্ডারের অবস্থা ও সংশ্লিষ্ট পরিস্থিতি যাচাই করে নেওয়া হবে।

🚫 নিষিদ্ধ কার্যক্রম

ভুয়া পেমেন্ট প্রমাণ, প্রতারণা, ভুল তথ্য দিয়ে অর্ডার করা বা অন্য কোনো সন্দেহজনক কার্যক্রম গ্রহণযোগ্য নয়। এমন কার্যক্রম শনাক্ত হলে অর্ডার বাতিল করা হতে পারে।

😂 ছোট্ট কিন্তু গুরুত্বপূর্ণ কথা

Diamond/Coins/UC কিন্তু মনের কথা বুঝতে পারে না! 😆
